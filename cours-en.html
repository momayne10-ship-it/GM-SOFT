Build Websites with AI & Build Your Independent Income

A 100% online hands-on course in 10 sessions — from programming basics and website types to directing AI, then building a full project across two sessions, and stepping into freelancing.

01

We start from zero: what programming is and how code becomes a website that runs online.

  • What programming is and how it works
  • Discovering the web development field
  • How is a website built?
  • The roles of front-end and back-end developers
Intro Fundamentals
02

We explore the different families of websites and the components every successful site needs before we start building.

  • Informational and business websites
  • E-commerce stores
  • Platforms and web applications
  • Content management systems
  • The core components of any website
Website types Components
03

We understand the difference between general AI tools and specialised agents, and when to use each of them.

  • What is artificial intelligence?
  • General AI tools vs. coding agents
  • The tools and how they are used in web development
AI Agents
04

Before writing code, we learn how to think: analyse the problem and turn the idea into an actionable plan.

  • Logical thinking
  • Problem analysis
  • Analysing project requirements
  • Algorithms and diagrams
  • Turning an idea into an actionable plan
Logic Analysis
05

We walk through the real stages of a project, step by step — from the idea all the way to publishing online.

  • Studying the idea and analysing requirements
  • Planning and structuring the project
  • UI/UX design
  • Choosing technologies and tools
  • Development and implementation
  • Testing and bug fixing
  • Publishing, hosting and connecting the domain
Stages Hands-on
06

The key skill: how to direct AI so it works with you accurately and efficiently inside your project.

  • Prompt Engineering
  • Context Engineering
  • Loop Engineering
  • Task breakdown and directing agents
  • Reviewing results and fixing errors
  • Managing project context
Communication AI

We start building the real project: from the idea and requirements to planning, design and the core structure of the website — part one of the build.

  • Choosing the project idea and analysing requirements
  • Planning and structuring the project
  • UI/UX design
  • Setting up the workspace and tools
  • Building the core pages and overall structure
Project — Part 1 First build

We finish what we started in Session Seven: completing the remaining pages and features, adding content, then testing and publishing online — part two of the build.

  • Completing the remaining pages and features

  • Testing, fixing errors and improving performance
  • Publishing, hosting and connecting the domain
Project — Part 2 Launch

Trainees are tasked with creating a website based on an idea of their choice, with evaluation of execution quality, design, functionality and user experience.

  • Choosing and presenting a creative idea
  • Building the website independently
  • Evaluating execution quality and design
  • Evaluating functionality and user experience
Creativity Challenge

Your skills are ready — now we learn how to turn them into independent income through freelancing.

  • What freelancing is
  • Freelancing platforms
